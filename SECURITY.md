# Security Policy

## Supported Versions

Only the latest released version on each active branch receives security
fixes:

| Branch  | Jellyfin target | Supported |
| ------- | --------------- | --------- |
| `main`  | Current LTS     | Latest release only |
| `10.11` | 10.11           | Latest release only |

Older tagged releases on either branch are not patched - upgrade to the
latest release on your branch to get a fix.

## Reporting a Vulnerability

Please **do not** open a public issue for a security vulnerability.

Instead, use GitHub's private vulnerability reporting:
[Report a vulnerability](https://github.com/Marnalas/jellyfin-subsync/security/advisories/new).
This lets us discuss and fix the issue before it's disclosed publicly.

This is a small, community-maintained project without a dedicated security
team, so there's no guaranteed response time - but reports will be
acknowledged and looked at as soon as possible.
