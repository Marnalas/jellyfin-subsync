Subsync cache

Subsync skips a subtitle it has already synced, so repeat sweeps don't redo the same work. Use this page to make it forget - either everything, or just what it knows about one item.

Clear everything

Clearing the cache makes every tracked subtitle look unsynced again, so the next sweep re-checks all of them.

Clear one item

Find the item, then clear just its cached subtitles - useful after manually fixing a subtitle so it gets re-synced instead of being skipped as already synced.
