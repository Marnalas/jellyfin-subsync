Configure the connection to the ffsubsync GPU sidecar and which library paths to scan.

Base URL of the subsync-sidecar service, e.g. http://subsync-sidecar:8000 (use the docker compose service name so it resolves on the internal network).
One absolute path per line, as seen INSIDE the Jellyfin container (e.g. /media/films, /media/films4k, /media/series). These must match your compose volume mounts.
Common prefix shared by all watched paths above, e.g. /media
The equivalent prefix as mounted in the sidecar container, e.g. /mnt/media. Used to translate a Jellyfin-side path into the folder argument the sidecar expects.
Comma-separated, no dots, e.g. mkv,mp4,m4v,avi,ts,mov,wmv
