Subsync

Configure the connection to the ffsubsync GPU sidecar and which library paths to scan.

Base URL of the subsync-sidecar service, e.g. http://subsync-sidecar:8000 (use the docker compose service name so it resolves on the internal network).
One library per line, in the form jellyfin-path : sidecar-path, e.g. /path/to/jellyfin/library : /path/in/sidecar/container. The left side is the path as seen INSIDE the Jellyfin container (must match your compose volume mounts); the right side is the equivalent path as seen by the subsync-sidecar container. Each line is independent - there's no shared root requirement between libraries, so they can be mounted under completely different layouts on each side.
Comma-separated, no dots, e.g. mkv,mp4,m4v,avi,ts,mov,wmv
How many subtitle files the sweep submits to the sidecar at once. Default is 1. Raising this only helps if the subsync-sidecar container's own MAX_PARALLEL_JOBS environment variable is also raised - the sidecar itself defaults to (CPU cores - 1) worker threads, but if you leave this plugin setting at 1, only one file is ever in flight regardless of how many the sidecar could run. Conversely, raising this past the sidecar's actual worker count just queues extra jobs there without speeding anything up. Set both together, sized to the sidecar container's available CPU.

The sweep's schedule (default: daily at 02:00, plus once on every server startup) is edited separately, from Dashboard > Scheduled Tasks > "Sync unsynced subtitles" > Edit - same place as any other Jellyfin task.
